# Senai_Back-End

Repositório com aulas e atividades do segundo termo do curso Técnico de Desenvolvimento de Sistemas, com foco em desenvolvimento Back-End.

## 📚 Conteúdo

Este repositório reúne exercícios, exemplos e implementações práticas abordando os seguintes temas:

- **APIs RESTful**
  - Com e sem uso de DTOs (Data Transfer Objects)
  - Integração com Front-End
- **Padrões de Projeto**
  - Implementação do padrão **Builder**
- **Configurações de Projeto**
  - Estruturação de diretórios e boas práticas

## 🚀 Objetivo

Praticar os fundamentos do desenvolvimento de APIs, organização de código e aplicação de boas práticas de desenvolvimento no Back-End.
